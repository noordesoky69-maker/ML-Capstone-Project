# Smart Predictive Maintenance

## Project Overview
Smart Predictive Maintenance is a Machine Learning project that aims to analyze industrial machine data and predict machine performance and failures.

## Dataset
AI4I 2020 Predictive Maintenance Dataset.

## Project Objectives
- **Regression:** Predict machine Torque.
- **Classification:** Predict whether a machine will fail.
- **Clustering:** Group machines based on their operating conditions.

## Project Structure
- `data/`: Raw and cleaned datasets.
- `notebooks/`: Jupyter notebooks and machine learning code.
- `results/`: Visualizations and model evaluation results.

## Tools and Technologies
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
